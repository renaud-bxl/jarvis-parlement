Mode d’emploi de Jarvis Parlement 2

Jarvis réunit les recherches, les projets parlementaires, les documents, les courriers et l’agenda dans une application Mac. Son contenu est un travail préparatoire : vérifie les sources, les compétences, les destinataires et les procédures avant tout dépôt.

Installation sur un premier Mac ou mise à jour

  1. Décompresse l’archive et ouvre Installer Jarvis Parlement.app.
  2. Clique sur Installer et ouvrir Jarvis, ou sur Mettre à jour et ouvrir Jarvis. L’installateur détecte les données existantes.
  3. Garde l’option LibreOffice si tu veux des PDF produits à partir de tes modèles Word. Internet est nécessaire ; plusieurs gigaoctets peuvent être téléchargés pour le moteur local.
  4. À la fin, Jarvis s’ouvre. Complète le profil et choisis la connexion IA. Les comptes Google doivent être autorisés dans le navigateur.
  5. Les lancements suivants se font avec Jarvis Parlement.app, dans le dossier Applications de ton compte. Un raccourci est ajouté au Bureau lorsque ce dossier est disponible.

Configuration cible : macOS 14 ou ultérieur, Apple Silicon ou Intel. Les modèles locaux sont plus lents sur Intel. L’installateur ne supprime ni les modèles Ollama, ni les courriers, ni les documents. L’ancien environnement OpenJarvis est conservé ; la nouvelle interface utilise son propre environnement de dépendances.

Cette distribution n’est pas signée ni notariée par Apple. macOS peut demander une autorisation d’ouverture : après vérification de l’origine du fichier, utilise Réglages Système → Confidentialité et sécurité → Ouvrir quand même si cette option apparaît. Ne désactive pas Gatekeeper. Une politique d’entreprise peut nécessiter l’intervention de l’administrateur.

Le profil de chaque utilisateur

Dans 6. Configuration → Profil de rédaction, indique le nom complet du parlementaire, sa fonction, son institution et la langue par défaut : français, néerlandais ou anglais. Le nom du collaborateur est facultatif. Le parlementaire est le signataire ; le collaborateur n’acquiert pas ce mandat.

Aucun utilisateur n’est automatiquement identifié comme Geoffroy Coomans de Brachène. Chaque nouvelle installation commence avec un profil vide. Pour rédiger ponctuellement au nom d’une autre personne, indique-le explicitement dans la demande et vérifie la signature du modèle, qui suit le profil enregistré.

1. Recherche web et projet parlementaire

Décris le sujet, l’institution compétente et le livrable attendu. Active Recherche web pour les informations récentes. Le périmètre prévu couvre Bruxelles, le fédéral et le Parlement Benelux ; tu peux préciser un autre parlement. Les règles propres à chaque assemblée restent à vérifier.

Exemple : « Recherche les dernières publications officielles du Parlement Benelux sur la mobilité transfrontalière, distingue les recommandations et les décisions, puis propose cinq questions avec les sources et dates. »

Pour produire un document conforme à un modèle actif, renseigne les Champs du document parlementaire : objet, destinataire et formule d’appel. Les champs manquants restent visibles comme éléments à préciser. Une recherche doit établir les destinataires actuels ; les ministres mentionnés dans les exemples de 2022 ne sont pas repris comme titulaires actuels.

La conversation transmet les huit derniers éléments d’historique, bornés en longueur. « Nouvelle conversation » remet ce contexte à zéro, sans supprimer les rapports. Les liens de sources s’ouvrent dans le navigateur. Les modèles locaux de petite taille peuvent échouer à appeler la recherche ; Jarvis signale l’absence d’un appel web détecté au lieu de présenter le résultat comme une recherche effectuée.

2. Analyser un document local sans recherche web

Choisis un PDF, DOCX, TXT, MD ou CSV, puis donne la consigne d’analyse. La recherche web est désactivée. L’extraction est limitée à 100 pages PDF et 70 000 caractères ; elle ne constitue pas un traitement intégral des fichiers plus longs. Les PDF scannés nécessitent un OCR préalable.

Une analyse utilise l’IA sélectionnée. Avec Ollama, le calcul reste sur le Mac. Avec un fournisseur cloud, tu dois activer explicitement l’autorisation de traiter les données privées. Le fichier n’est pas ajouté à l’index sans une action d’indexation séparée.

3. Briefing du jour

Le briefing recherche les publications récentes sur les thèmes enregistrés. Il couvre les dernières 24 heures selon la date de génération et conserve le résultat dans les rapports. Les sites officiels sont prioritaires ; aucune couverture exhaustive n’est garantie.

Dans Configuration, modifie les thèmes, active le briefing quotidien et règle l’heure. Une migration reprend l’horaire inscrit dans l’ancien planning, notamment 10 h 30 lorsqu’il avait été choisi. L’horaire suit le fuseau du Mac. La session doit être ouverte et le Mac disponible ; après une veille, macOS peut différer une exécution jusqu’au réveil. Le programme ne garantit pas un réveil de la machine.

Les courriers et agendas sont facultatifs. Les synthèses privées restent séparées des requêtes de recherche publique. Les courriers du briefing sont résumés par Ollama local ; les événements de l’agenda sont ajoutés sans appel à une IA. Le transfert manuel vers une app ne permet pas de briefing autonome.

4. Lire et résumer une boîte mail localement

Sélectionne une boîte puis clique sur Lire les 5 derniers messages. La lecture ne transmet pas les messages à une IA et ne les marque pas volontairement comme lus. La synthèse de cette rubrique utilise Ollama local, même si tu as choisi une API pour les recherches parlementaires. Configure d’abord un modèle local dans Configuration.

Le connecteur ne garantit pas que les cinq derniers messages datent du jour. Les pièces jointes ne sont pas analysées automatiquement. Les messages sans partie texte peuvent nécessiter une consultation dans ton application mail.

5. Envoyer un fichier eml par SMTP après validation

  1. Sélectionne un compte IMAP/SMTP. Le connecteur Gmail OAuth de cette version est en lecture seule.
  2. Choisis le fichier .eml, puis clique sur Prévisualiser le .eml.
  3. Relis l’expéditeur, les destinataires, l’objet, le texte et la liste des pièces jointes. Pour un message uniquement HTML, ouvre aussi l’original dans ton logiciel mail avant de confirmer.
  4. Clique sur Confirmer et envoyer ce message, puis valide la boîte de confirmation macOS.

Les octets validés sont ceux envoyés, même si le fichier d’origine est modifié entretemps. La validation ne peut être utilisée qu’une fois. L’expéditeur doit correspondre au compte SMTP. Les en-têtes Bcc, Resent, Sender, Return-Path et les en-têtes principaux dupliqués sont refusés. L’accusé indique l’acceptation par le serveur, pas une garantie de livraison. En cas de délai dépassé pendant l’envoi, vérifie les messages envoyés avant de réessayer pour éviter un doublon.

Tu peux également composer un courrier texte dans l’application. Aucune réponse de l’IA ne provoque automatiquement un envoi.

6. Ajouter ou modifier la configuration

Les réglages regroupent le profil, les IA, la voix, le planning et les comptes. Clique sur Enregistrer les réglages après modification. Enregistrer une clé n’enregistre pas à lui seul le choix du moteur ou du modèle.

Gmail et Google Calendar

  1. Dans Google Cloud, utilise un projet avec Gmail API et, pour l’agenda, Google Calendar API activées.
  2. Configure l’audience OAuth et les utilisateurs autorisés selon ton compte ou ton organisation.
  3. Crée ou utilise un client OAuth de type Application de bureau, puis télécharge son JSON.
  4. Dans Jarvis, donne un nom au compte, sélectionne le JSON et coche l’accès agenda si nécessaire.
  5. Autorise le compte dans le navigateur et reviens dans Jarvis.

Pour ajouter l’agenda à un Gmail déjà configuré, réutilise exactement son nom de compte. Les autorisations de lecture sont conservées au Trousseau. L’ancien kit ouvrait un connecteur Drive pour l’agenda ; cette connexion ne remplace pas l’autorisation Calendar de la nouvelle interface.

Google peut exiger une nouvelle connexion selon le statut de test de ton projet, la politique de ton organisation ou l’expiration/révocation du jeton. Le mot de passe Google se saisit sur Google, jamais dans Jarvis.

IMAP et SMTP

Indique l’adresse, les serveurs et les identifiants fournis par l’hébergeur. IMAP utilise TLS sur 993 ; SMTP utilise TLS direct sur 465 ou STARTTLS sur 587. Les identifiants IMAP et SMTP peuvent différer. Utilise un mot de passe applicatif si ton fournisseur l’exige. Les deux connexions sont vérifiées avant l’enregistrement. Un compte utilisant une politique OAuth spécifique peut refuser l’authentification par mot de passe ; utilise alors le connecteur approprié.

7. Indexer les documents

Sélectionne de 1 à 20 fichiers, puis lance l’indexation locale. Le texte est conservé dans une base SQLite sur le Mac. La limite est de 30 Mo par fichier et 70 000 caractères extraits. Deux fichiers portant le même nom remplacent la même entrée ; renomme-les si tu veux conserver les deux. Les scans doivent être passés à l’OCR au préalable.

8. Chercher dans l’index documentaire

Saisis des mots-clés pour obtenir jusqu’à douze extraits classés par le moteur de recherche local. Cette recherche n’appelle pas une IA et n’effectue pas de recherche Internet. Il s’agit d’un index textuel, pas d’une mémoire sémantique exhaustive. Pour analyser un résultat complet, sélectionne le document d’origine dans l’analyse documentaire.

9. Diagnostic

Le diagnostic vérifie la présence des composants et l’accès aux modèles Ollama. Le test IA envoie une vraie requête au moteur enregistré. La lecture des mails et le chargement de l’agenda testent les comptes concernés. Un composant « présent » ne signifie pas que son compte distant est autorisé.

Si la fenêtre ne s’ouvre pas, consulte ~/.config/jarvis-parlement/application.log. Le journal d’installation est ~/.config/jarvis-parlement/installation-v2.log. Le bouton de journal de l’installateur l’ouvre sans commande à saisir. Ne publie jamais de clé, fichier OAuth ou jeton dans un ticket ou une capture.

10. Connecter Google Calendar

La connexion native Google est configurée dans la rubrique des comptes Google en cochant l’agenda. L’écran Agenda affiche les sept prochains jours en lecture seule, jusqu’à 100 événements. primary désigne l’agenda principal ; tu peux entrer un identifiant d’agenda partagé accessible au compte. Cette version ne crée ni ne modifie les rendez-vous.

11. Retirer la veille automatique

Le bouton dédié désactive le service planifié et conserve les rapports, les thèmes et les comptes. Pour le réactiver, coche le briefing quotidien dans Configuration et enregistre. La désactivation d’une prochaine exécution n’arrête pas forcément un briefing déjà en cours.

Templates parlementaires

Trois mises en page bruxelloises sont préparées à partir des exemples fournis. Elles conservent la présentation institutionnelle et remplacent les noms, sujets et anciens destinataires par des champs variables. Ces modèles ne sont pas des formulaires certifiés par une assemblée et ne doivent pas servir sous le logo bruxellois pour une autre institution.

  1. Importe l’exemple Word fourni par ton institution, en .docx ou .doc. Le format .doc est converti par macOS : contrôle le résultat.
  2. Donne un nom au parlement ou à l’institution.
  3. Si ton modèle contient un paragraphe isolé {{JARVIS_CONTENT}}, cette zone est reconnue. Sinon choisis le premier et le dernier paragraphe de la partie à remplacer. Le contenu entre eux, tableaux compris, sera retiré.
  4. Vérifie les parties conservées : remplace les anciens noms, dates et sujets par des champs variables dans Word avant import. Les sauts de section ne doivent pas traverser la zone remplacée.
  5. Active le modèle et génère un aperçu. Ouvre le Word et le PDF pour contrôler la police, les espacements, les logos, les marges et les sauts de page.

Champs reconnus : {{FULL_NAME}}, {{ROLE}}, {{INSTITUTION}}, {{SUBJECT}}, {{RECIPIENT}}, {{SALUTATION}} et {{JARVIS_CONTENT}}. Le corps conserve le style du premier paragraphe de la zone remplacée. Les titres Markdown peuvent utiliser les styles de titre du modèle ; les listes complexes, zones de texte flottantes et formulaires particuliers peuvent nécessiter un ajustement manuel dans Word. Les modifications suivies et commentaires doivent être retirés avant import.

Le modèle actif s’applique aux nouveaux exports. Choisis celui de l’institution et du type de document avant de générer. Les anciens rapports ne sont pas modifiés. Aucun modèle n’est activé sur une nouvelle installation afin d’éviter d’imposer une identité institutionnelle incorrecte.

Pour le PDF, Jarvis convertit le Word via LibreOffice afin de conserver la mise en page du modèle. Si LibreOffice manque ou échoue, le Word est conservé et Jarvis explique l’absence du PDF : il ne substitue pas une mise en page différente. Tu peux aussi ouvrir le Word dans ton logiciel habituel et exporter le PDF. Pour installer LibreOffice : téléchargement officiel.

Voix et dictée

« Lire automatiquement les réponses » utilise la synthèse vocale de macOS. Les boutons Écouter et Arrêter sont disponibles sur les résultats. La voix utilisée dépend des réglages de parole du Mac. La dictée s’utilise avec le raccourci défini dans Réglages Système → Clavier → Dictée, lorsque le champ de saisie a le focus. Cette version n’inclut pas de mot de réveil permanent ni d’écoute continue.

Confidentialité, sauvegarde et retour arrière

Les paramètres et l’index se trouvent dans ~/.config/jarvis-parlement. Les secrets sont au Trousseau macOS. Les documents produits se trouvent dans ~/Documents/Jarvis-Parlementaire. Ces documents et l’index sont protégés par les permissions du compte, mais ne disposent pas d’un chiffrement applicatif supplémentaire ; active FileVault si ton organisation le prévoit.

L’utilisation d’une API ou d’un compte ChatGPT transmet les demandes au fournisseur sélectionné. Le consentement « données privées » est distinct du choix du fournisseur. Une demande marquée privée et son historique ne sont pas envoyés au moteur web. Le transfert manuel vers une app copie le texte au presse-papiers ; tu décides ensuite de le coller.

Avant une mise à jour, l’installateur copie les réglages principaux et le planning dans ~/Applications/Jarvis-Parlement/backups. Les secrets ne sont pas exportés. Les anciennes versions sont conservées dans versions. Cette sauvegarde de migration n’est pas une sauvegarde complète : utilise Time Machine ou la politique de sauvegarde de ton organisation pour les documents, les modèles et le Trousseau.

Pour revenir en arrière, ferme Jarvis, ouvre la sauvegarde souhaitée puis utilise Restaurer cette version.command. Cette opération rétablit les réglages sauvegardés, le planning et l’ancienne application lorsque disponibles. Elle ne supprime pas les nouveaux rapports. Une restauration vers le kit V1 rétablit son menu Terminal. Lis le résumé affiché avant la confirmation.

Tour guidé, sources et limites

Le tour apparaît à la première ouverture et peut être relancé depuis l’aide. Les menus portent les onze numéros du workflow. Les raccourcis permettent aussi d’ouvrir les dossiers et les rapports.

La recherche web dépend des moteurs et de leur disponibilité. Un résultat doit être relu. Les dates, chiffres, citations et procédures ne sont pas garantis par l’IA. La connexion OAuth, les API réelles, la voix, l’installateur natif et les permissions doivent être validés sur le Mac de destination. Le programme ne peut pas révoquer automatiquement les secrets exposés dans une ancienne capture.
